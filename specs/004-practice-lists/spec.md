## Goal

Publish three easy-to-find lists in the practice room. Recover the previous easy and puzzle shortlists and use the audited task catalog to broaden them.

## Requirements

- **ez** includes the earlier easy shortlist and additional approachable tasks across several subjects. Each entry opens its statement, files and evaluation instructions.
- **realeyes** collects easy and medium tasks that reward a task-specific observation or method. Shared tasks keep one page and attempt history. Hints are collapsed on task pages.
- **O7** replaces the **Hard?** label. The old `#hard` link, existing task links and the Global Campus collection continue to open.
- Lists mark access and grading limits. Existing practice packs, timers and notes continue to work.

## Acceptance

Open the lists and representative task tabs on desktop and mobile. Check an original pack, a shared task, an optional hint and navigation through the old `#hard` link. Verify the published GitHub Pages build.
